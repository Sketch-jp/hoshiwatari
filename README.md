# ほしわたり

**遊ぶ：https://sketch-jp.github.io/hoshiwatari/**

タップひとつで星から星へ。輪のふちをかすめて「ギリギリ！」を重ねる、日替わりコースのワンタップゲームです。

## 遊び方

- 彗星は星のまわりを回っています。タップ（クリック／スペースキー）すると、その向きへまっすぐ飛びます
- 次の星の点線の輪に入れば成功。上へ上へと渡っていきます
- 輪のふちを横からかすめると「ギリギリ！」。続けるとコンボで点が増えます
- 次の星を飛び越えて先の星に入ると「とびこし」ボーナス
- 同じ星を回り続けると輪が縮み、ゼロで墜落します

「今日のコース」は日本時間の0時に切り替わり、その日は全員が同じ星空で遊びます。

## 技術

HTML・CSS・JavaScript（Canvas、Web Audio）だけで動きます。外部ライブラリ、外部素材、広告、アクセス解析は使っていません。記録はお使いのブラウザの中（localStorage）にだけ保存されます。
